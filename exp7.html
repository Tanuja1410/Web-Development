Demonstration of Link Tag in HTML

This page shows different uses of the <link> tag.


# Link Tag Usage Code Example
1 External CSS <link rel="stylesheet" href="style.css">
2 Print CSS <link rel="stylesheet" href="print.css" media="print">
3 Favicon <link rel="icon" href="favicon.png" type="image/png">
4 Preload Resource <link rel="preload" href="style.css" as="style">
5 Google Font <link rel="stylesheet" href="https://fonts.googleapis.com/...">
